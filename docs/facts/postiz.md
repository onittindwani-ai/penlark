# Postiz

Read on 2026-11-23 from https://docs.postiz.com/public-api/introduction. Base URL `https://api.postiz.com/public/v1`. The key goes in the `Authorization` header with no `Bearer` prefix (OAuth tokens start with `pos_`). Create a post with `POST /public/v1/posts`: `type` (`schedule` with a `date`, `now`, or `draft`), `date` as ISO 8601, `shortLink`, `tags`, and `posts[]` each with `integration.id`, `value[]` of `content` and `image`, and `settings.__type` matching the provider (`x`, `linkedin`, `instagram`). Rate limit: 90 requests an hour on a self hosted default, applied only to the create post endpoint, changeable with `API_LIMIT`. Penlark's adapter sends exactly this body and was tested only against `mock/scheduler_mocks.py`. The same page embeds an OpenAPI 3.1.0 spec: `type` is draft, schedule or now, `date`, `shortLink` and `tags` are required, `posts` is required unless the type is draft, and the response is a list of `postId` and `integration`. Excerpt and contract test: `mock/contracts/postiz/`, `mock/tests/test_contracts.py`. Still never run against a real account.
